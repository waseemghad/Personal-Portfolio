# Portfolio Blog

A personal blog/portfolio site built with PHP and MySQL, featuring user sessions and login-gated pages.

**Version:** 1.0

**Live demo:** https://wghad.byethost7.com/index.html

## Tech Stack

- PHP 8.1
- MySQL
- HTML/CSS

## Features

- Session-based authentication
- Login-gated content (redirects unauthenticated users)
- Blog post storage and retrieval via MySQL
